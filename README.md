# ShaadiOS MVP Prototype

ShaadiOS is an India-first wedding coordination system. This interactive prototype focuses on the MVP wedge: it turns one wedding into a connected plan and explains what needs attention, why it matters, and what a major change affects.

## Included journey

1. Landing page and progressive wedding setup
2. Generated initial plan with clear next actions
3. Wedding dashboard with priorities, risks, dependency context, and health
4. Timeline, tasks, people, vendor pipeline, and contextual planner views
5. Date-change impact review with explicit approval before updates are applied

## Local run

```powershell
pnpm install
pnpm dev
```

Use the **Try date change** action in the dashboard to experience the differentiated change-management flow.
